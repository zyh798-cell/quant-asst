# Quant Asst 禁用清单

本清单列出前端实现中明确禁止的界面做法，每条给出判定依据与替代方案。规则提炼自 hallmarK 的 slop 检测闸门（`references/gates.md`）与 impeccable 的审计维度（排版、色彩、动效、对比度、可访问性）。

对应等级：

- **Floor**：不可豁免。违反即视为缺陷，不得发布。
- **Reflex**：模型默认倾向。确有理由可豁免，但需在代码注释中记录理由与证据。
- **Finish**：打磨项。汇报并处理，不阻断。

---

## 1. 颜色与表面

### 1.1 紫粉渐变（Floor）

**禁用**：紫到蓝、紫到粉、青色渐变到深色的任何渐变，包括 `background-clip: text` 的渐变文字。

**原因**：训练数据的通用默认色，一眼可辨为 AI 生成。

**替代**：单一锚点色（青绿 `#18A67C`）配实色文字。强调靠字重与字号表达，不靠渐变。

### 1.2 其他色相的渐变文字（Reflex）

**禁用**：任何非紫系的渐变文字。

**豁免条件**：单色相渐变（色相跨度 40° 以内）且两端均为设计令牌。

**替代**：实色文字 + 字重或展示字体。

### 1.3 纯黑白与绝对色（Floor / Reflex）

**禁用**：在令牌块之外使用 `#000`、`#fff`、`oklch(0% …)`、`oklch(100% …)` 作为颜色。

**原因**：与暖纸面 + 青绿的锚点色系脱节。

**替代**：纸面向锚点色相偏移，chroma 不低于 0.005。卡片白以 `--color-surface` 表达。

### 1.4 零 chroma 中性灰（Reflex）

**禁用**：页面锚点色为青绿时使用纯灰（chroma = 0）作为中性色。

**替代**：使用 `TOKENS.md` 1.2 的暖调中性色阶。

### 1.5 强调色泛滥（Reflex）

**禁用**：强调色超过视口 8%（密集数据面板 5%），且未声明视觉姿态。

**替代**：强调色承载信息（主行动、关键序列、风险提示），其余用中性色。

### 1.6 光晕与弥散（Reflex）

**禁用**：文字背后的极光 / 网格光斑、漂浮模糊球、色调径向光晕、深色模式下的零偏移彩色发光阴影。

**替代**：实色或微纹理表面；层次靠明度台阶与带偏移的阴影。

### 1.7 框架默认调色板（Reflex）

**禁用**：直接引用框架默认色（Tailwind `indigo-500`、`violet-600`、`slate-900` 等）作为令牌或工具类。

**替代**：按本产品的锚点色相在 OKLCH 中自行调配。

### 1.8 渐变与彩色光晕在图表中的滥用（Floor）

**禁用**：3D 图表、标记阴影、柱体渐变。

**替代**：实色标记 + 明确的数值编码。

## 2. 字体与排版

### 2.1 默认字体堆砌作为展示标题（Reflex）

**禁用**：以 Inter、Roboto、Open Sans、Poppins、Lato 或系统字体作为展示标题。

**替代**：使用 `TOKENS.md` 2.1 定义的 `--font-display`；正文族可保留 Inter。

### 2.2 标题中夹带斜体或单独强调词（Floor / Reflex）

**禁用**：
- 全正体标题中出现单个斜体词（Floor）。
- 标题中单独把一个词或短语染成强调色、加粗或加高亮底（Reflex）。

**替代**：整个标题一种字重、一种样式、一种颜色；用换行或第二个字号层级制造节奏。

### 2.3 展示标题全大写且行高过低（Floor）

**禁用**：全大写标题在 `line-height < 1.0` 时可能换行。

**替代**：行高至少 1.0，推荐 1.02 至 1.08。

### 2.4 等宽字体当装饰（Reflex）

**禁用**：在标签、说明、元信息行、表头等非代码内容上使用等宽字体，只为营造「技术感」。

**替代**：等宽仅用于代码、行情代码、指标数字与度量值；标签用正文字体、小一号、正常字重。

### 2.5 全大写小字标签（Floor，house rule）

**禁用**：15px 及以下的标签、说明、表头、导航项、徽章设为全大写或小型大写，或字距超过 0.03em。

**合法例外**：品牌字标；页面主展示本身即全大写的页面上，其控件标签可全大写且字距不超过 0.04em。

**替代**：正文字体、小一号、句首大写、零字距。

### 2.6 文字过挤（Reflex）

**禁用**：正文小于 12px；功能性文字小于 11px；多行正文行高低于 1.3。

**替代**：正文 16px、行高 1.55 至 1.65；标签小一号。

### 2.7 超宽行（Reflex）

**禁用**：正文 `max-width` 超出 45ch 至 75ch，或实际渲染行宽约 88 字符以上。

**替代**：`max-width: 65ch`。

### 2.8 字体族过多（Reflex）

**禁用**：同一页面使用三套以上字体族。

**替代**：标题 / 正文 / 一套例外字体，不超过三套。

## 3. 结构与布局

### 3.1 卡片套卡片（Floor）

**禁用**：卡片内部再嵌卡片。

**替代**：一层容器。分组用分隔线、间距或底色区分。

### 3.2 雷同卡片堆叠（Reflex）

**禁用**：三列等宽的「图标在上、标题在下」同质卡片；图标装在圆角方块里置于标题上方；卡片上使用粗彩色侧边条。

**替代**：变化宽度与高度；图标内联；用细线或无边框。

### 3.3 眉标 / eyebrow（Floor，house rule）

**禁用**：标题上方放一行短的无信息量文字作为眉标，包括堆叠、并排、药丸、序号、分类标签形式。

**合法例外**：`<figcaption>`、`<th>`、`<label>`、导航或标签页名称、署名或 `<time>`、数字后的单位、真实文件名、实时 `role="status"` 状态、指向真实位置的单一公告。

**替代**：换一种方式开区（直接以标题起势，或以数据起势）。

### 3.4 模板标点（Floor，house rule）

**禁用**：
- 用间隔号连接元信息串（`A · B · C`）。
- 箭头紧贴链接或按钮文字（`了解更多 →`）。
- 标签前的装饰性状态圆点。
- `WORD - fragment` 形式的标签。

**合法例外**：署名、图注、实时状态中各出现一个点；跑马灯的重复分隔符。

**替代**：换行、分栏、细线分隔；用动词作为标签。

### 3.5 AI 模板页结构（Reflex）

**禁用**：首屏 + 三个特性 + 行动号召 + 页脚的固定套路，或与最近三次构建同形。

**替代**：按产品任务设计结构。

### 3.6 章节间距全部相同（Reflex）

**禁用**：每个章节之间用完全相同的间距分隔。

**替代**：按表面阶梯（留白 / 细线 / 淡底 / 卡片）在不同位置使用不同分隔方式。

### 3.7 硬编码间距（Floor）

**禁用**：在存在 `--space-*` 令牌的情况下，直接写 `padding: 16px`、`margin: 24px`、`gap: 12px`。

**替代**：引用令牌。

### 3.8 横向滚动（Floor）

**禁用**：320px 至 1920px 任一宽度出现横向滚动；缺少 `html` / `body` 上的 `overflow-x`；使用 `100vw` 宽度。

**替代**：`overflow-x: clip`，容器用 `width: 100%`。

### 3.9 网格轨道缺少下限保护（Floor）

**禁用**：带图片的网格轨道使用裸 `1fr`；展示标题缺少 `overflow-wrap: break-word; min-width: 0`。

**替代**：`minmax(0, 1fr)`；`break-word`（不用 `anywhere`）。

### 3.10 两个吸顶元素冲突（Floor）

**禁用**：页面同时存在两个 `position: sticky; top: 0` 元素，导航会被遮挡。

**替代**：第二个改用 `top: var(--banner-height)`；`--z-sticky-nav` 高于 `--z-sticky`。

### 3.11 标题与其下方内容距离过近（Reflex）

**禁用**：标题上方留白小于下方留白的 0.75 倍（且差 12px 以上）。

**替代**：标题上方留白至少为下方的两倍。

### 3.12 盒内文字贴边（Reflex）

**禁用**：填充盒或带侧边框盒内，文字距左右小于 `max(8px, 0.5em)`、距上下小于 `max(4px, 0.3em)`；手机上正文距屏幕边缘不足 8px。

**替代**：加内边距；手机端 16px 留白。

### 3.13 章节标题过小（Reflex）

**禁用**：1440px 下，首屏之后的 `h2` 中位渲染尺寸低于 40px。

**替代**：`h2` 用 `--text-section`，条目标题用 `--text-title`。

### 3.14 装饰性插画冒充数据（Reflex）

**禁用**：以内联 SVG / CSS 画出物体、人物、场景、图表容器等作为装饰；或用渐变色块（≥300×200px）冒充内容。

**替代**：真实数据图表（明确标注 `class` 或 `aria-label`）、真实素材，或纯排版。

### 3.15 用重复符号表达数量（Reflex）

**禁用**：24 个以上相同的刻度、点、方块表示数量。

**替代**：直接用数字排版。

### 3.16 空槽过多（Reflex）

**禁用**：单页超过 5 个空 `data-slot`，或一行超过 4 个空槽。

**替代**：用排版列出名称、角色、事实。

### 3.17 事实重复（Reflex）

**禁用**：同一个事实（价格、时间、日期、计数）在四个及以上区块重复出现；或某区块末行只是重复其标题。

**替代**：每个事实只在其发挥作用的��方说一次。

## 4. 文案与元信息

### 4.1 模板文案（Floor）

**禁用**：
- 占位人名（Jane Doe）、创业模板名（Acme、Nexus）。
-  buzzword：seamless、robust、empower、supercharge、elevate、effortless、unlock、unleash、next-generation、world-class、best-in-class、industry-leading、mission-critical、future-proof。
- 反驳式句式连用三次以上（「不是功能，是平台」）。
- 破折号（em / en dash）连接句式。
- 填充式开头（「Built for the modern team」「In today's landscape」）。
- 主行动旁放通用次行动（Learn more / Get started / Book a demo）。

**替代**：用产品自己的名词说清产品做什么。

### 4.2 编造数据（Floor）

**禁用**：编造的指标、用户评价、Logo 墙、案例数量。

**替代**：真实数字、明确的占位符，或留空。

### 4.3 假发送（Floor）

**禁用**：表单或控件在没有真实请求的情况下显示成功（Sent、Reserved、Thanks）。

**替代**：接口未接上之前不显示成功态。

### 4.4 无效装饰文字（Reflex）

**禁用**：无信息量的竖排文字、滚动提示、首屏的版本徽章或 BETA 药丸、天气/语言条、首屏下的等宽全大写条。

**替代**：删除；丢失的事实改为图注或页脚一行。

### 4.5 章节编号（Reflex）

**禁用**：`01 / 02 / 03` 形式的章节编号，除非序号本身承载读者需要的信息。

## 5. 动效与交互

### 5.1 无差别过渡（Floor）

**禁用**：`transition: all`；对 `width`、`height`、`top`、`left` 做动画。

**替代**：逐属性声明，只动 `transform` 与 `opacity`。

### 5.2 内外边距过渡（Reflex）

**禁用**：对 `margin` / `padding` 做过渡。

**替代**：使用 `transform`。

### 5.3 无意义弹跳与抖动（Reflex）

**禁用**：UI 状态使用弹跳 / 回弹 / 橡皮筋缓动；同一元素叠加多种效果；图片在 hover 时缩放或旋转；非交互元素响应指针。

**替代**：指数缓出（`--ease-out`）；每个元素只有一个信号，作用在容器上。

### 5.4 焦点环淡入（Floor）

**禁用**：焦点环通过透明度或动画淡入。

**替代**：瞬时出现。

### 5.5 提示气泡聚焦延迟（Floor）

**禁用**：tooltip 的 focus 延迟与 hover 延迟相同。

**替代**：hover 延迟 800 至 1000ms，focus 延迟 0。

### 5.6 自动轮播无暂停（Floor）

**禁用**：自动轮播 / 自动旋转的内容在 hover 与 focus 时不暂停。

**替代**：hover 与 focus 均暂停；超过 5 秒的动效提供可见的暂停控件。

### 5.7 缺少交互态（Floor / Reflex）

**禁用**：可交互元素缺少 `:focus-visible`；焦点环与底色对比度低于 3:1；outline 被移除且无替代；缺少 `:active` 或 `:disabled`。

**替代**：焦点环对比度不低于 3:1、瞬时出现；八个交互态齐备。

### 5.8 未适配减少动效（Floor）

**禁用**：关键帧或 transform 过渡没有 `prefers-reduced-motion: reduce` 分支。

**替代**：减少空间位移，保留承载语义的状态变化。

### 5.9 视频与首屏图未优化（Floor / Reflex）

**禁用**：视频自动播放未加 `muted`；LCP 元素加 `loading="lazy"`；视频缺 `poster` 或优先级提示。

**替代**：`autoplay muted loop playsinline`；LCP 图用 `fetchpriority="high"`。

### 5.10 输入控件状态导致尺寸跳动（Floor）

**禁用**：状态切换时边框宽度变化；焦点环用 `border` 实现；输入框比相邻按钮高或矮；仅靠 opacity 表示禁用。

**替代**：边框恒定、用 `outline`、控件等高、禁用同时使用 opacity + `cursor: not-allowed` + 原生属性。

### 5.11 控件高度失控（Reflex）

**禁用**：营销页控件高度超出 44 至 52px。

**替代**：落地页 44 至 52px；应用界面 32 至 40px 并扩展点击热区。

### 5.12 内容默认不可见（Floor）

**禁用**：默认 `opacity: 0` 或 `visibility: hidden`，依赖 JavaScript 才显示。

**替代**：默认可见；仅在 `.js` 类下隐藏，或用 `@starting-style` 从可见状态起动画。

### 5.13 成功却弹 Toast（Reflex）

**禁用**：用户已经能看到的效果再弹成功提示。

**替代**：静默成功；Toast 只用于失败与不可见的效果。

## 6. 资产与可访问性

### 6.1 Emoji 当图标（Floor）

**禁用**：用 emoji 或 Unicode 字形代替图标。

**替代**：单一图标库（Lucide / Heroicons）或自绘 SVG，笔画与字重一致。

### 6.2 混用两套图标库（Reflex）

**禁用**：同一页面使用两套图标库。

**例外**：品牌或平台标识最多占两个位置。

**替代**：统一一套。

### 6.3 装饰元素未隐藏（Floor）

**禁用**：装饰性 `<svg>` / `<canvas>` / CSS 图形既无 `aria-hidden="true"` 也无标签。

**替代**：隐藏或命名。

### 6.4 图片损坏或缺署名（Floor）

**禁用**：`<img>` 无源或加载失败；图库照片无署名；付费图外链。

**替代**：真实文件，或图库照片在页脚署名。

### 6.5 对比度不足（Floor）

**禁用**：
- 正文对比度低于 4.5:1；大字号、图标、焦点环、字段边框低于 3:1。
- 按钮文字与填充色明度差在 5% 以内。
- 深色面板未切换文字色。
- 彩色表面上使用灰色文字。

**替代**：使用配对墨色令牌；彩色表面上的次要文字取同色相而非灰色。

### 6.6 令牌外字面量（Floor）

**禁用**：在令牌块之外出现颜色或 `font-family` 字面量。

**替代**：提升为令牌。

### 6.7 按钮文字换行（Floor）

**禁用**：按钮标签或主导航链接在 320px 至 1920px 任一宽度换行。

**替代**：缩短文案或 `white-space: nowrap`。

## 7. 金融数据产品专项

以下为 Quant Asst 场景下的补充禁用项，来自 `hallmark` 的 `references/data-viz.md`。

### 7.1 单一数值画成单柱图（Floor）

**禁用**：一个数值用一根柱子表示。

**替代**：数值卡片（大数字 + 文字限定语）。

### 7.2 饼图与仪表盘堆叠（Floor）

**禁用**：饼图、甜甜圈图、仪表盘；用环形墙或仪表行充当「数据丰富」。

**替代**：部分与整体用堆叠水平条；KPI 墙收敛为一个主数值 + 一个支撑图表 + 一张表。

### 7.3 双 Y 轴（Floor）

**禁用**：同一图上放两个 Y 轴。

**替代**：单位不同拆成两张小图（small multiples）。

### 7.4 截断坐标轴夸大差异（Floor）

**禁用**：柱状图基线不为 0 而夸大差异；网格线虚线；网格线超过 5 条。

**替代**：基线恒为 0；确需放大区间时显式标注「坐标轴自 94% 起」。

### 7.5 文字穿数据色（Floor）

**禁用**：标签、数值、轴文字使用数据序列色。

**替代**：文字用 `--color-ink` / `--color-muted`；序列靠色块加标签识别。

### 7.6 图表标记阴影（Floor）

**禁用**：给柱、点、线加阴影或渐变。

**替代**：实色标记；仅 sparkline 允许渐隐填充。

### 7.7 多色分类超出语义色域（Floor）

**禁用**：为区分分类引入彩虹色板，与界面其余部分的强调色体系冲突。

**替代**：同一色相上的明度阶，按固定顺序分配；参考序列用 `--chart-series-4`。

## 8. 例外与记录

- Floor 项不可豁免。
- Reflex 项确需豁免时，在相关 CSS 或组件文件顶部用注释记录：闸门编号、证据、理由。理由须针对本页内容，不少于 24 字符，不得是套话。
- 同一闸门连续三次豁免即视为团队风格，须固化进本文件而非继续豁免。
- 本清单与 `TOKENS.md` 冲突时，以 `TOKENS.md` 的具体数值为准；本清单负责判定「该不该用」。

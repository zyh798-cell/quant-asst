# Quant Asst 金融数据产品准则

面向工程实现的产品级准则，覆盖图表、控件、响应式与可访问性。

配套文件：
- 令牌定义：`docs/design/TOKENS.md`（色值、间距、字体只在此定义）
- 禁用项：`docs/design/ANTI_PATTERNS.md`

---

## 1. 图表

### 1.1 形式选择

先定形式，再画图。数据形态与形式的对应关系是硬约束。

| 数据形态 | 应采用 | 不采用 |
| --- | --- | --- |
| 单个数值 | 数值卡片（大数字 + 文字限定语） | 单柱图 |
| 2 至 5 个数值对比 | 数值行或水平条 | 环形图 |
| 时间序列 | 折线；嵌套在其他组件内时用 sparkline | 面积堆叠 |
| 超过约 7 个分类 | 表格 | 换更多颜色 |
| 部分与整体 | 堆叠水平条 | 饼图、甜甜圈、仪表盘 |

量化研究场景补充：回测净值曲线用折线；策略持仓分布用水平条；策略对比用多行净值小图（small multiples），不用双轴叠加。

### 1.2 构造规范

- 柱条：厚度不超过 24px，间隙 2 至 4px，基线恒为 0，数据端圆角不超过 2px。
- 折线：描边 2px；标记点只出现在被标注的位置，直径不小于 6px。
- 网格线：1px 实线 `--chart-grid`，水平 3 至 5 条，不虚线；轴线可作为网格的第一条线。
- 坐标轴：仅一条 Y 轴。单位不同拆成两张小图。
- 禁止 3D、标记阴影、标记渐变（sparkline 的渐隐填充除外）。
- 容器内嵌 sparkline：无坐标轴、无网格、无第二种颜色。

### 1.3 配色

- 单序列：`--chart-series-1`（青绿 `#18A67C`）。
- 多序列：同一色相的明度阶（L 步进 12% 至 15%，chroma 恒定），按固定顺序分配，不循环复用。
- 上下文或参考序列：`--chart-series-4`（`#6B6660`）。
- 第二色相仅在明确声明的「全色板」姿态下使用，且必须来自已声明的角色，不得在图表中途凭空引入。
- 文字不穿数据色：标签、数值、轴文字用 `--color-ink` / `--color-muted`，序列靠色块加文字标签识别。

### 1.4 买卖信号标记

回测图上的交易点标记约定：

| 项 | 规范 |
| --- | --- |
| 买入标记 | `--chart-buy`（`#C0392B`），向上三角，位于 K 线下方 |
| 卖出标记 | `--chart-sell`（`#18A67C`），向下三角，位于 K 线上方 |
| 形状 | 统一 8px 实心三角，同一字段内不混用形状 |
| 描边 | 无阴影；hover 时才允许描边加粗，不做缩放 |
| 数量 | 不做逐笔数量堆叠；数量用 tooltip 或表格承载 |
| 标注 | 交易点必须可读：hover 提示显示标的、方向、价格、时间、股数 |

信号不得仅靠颜色区分（红绿对色觉障碍用户不可靠），必须同时有形状差异。

### 1.5 可读性

- 数值表面全部使用 `font-variant-numeric: tabular-nums`，保证列对齐。
- 坐标轴标签最小 12px（`--text-caption`），不得低于 11px。
- 单一图表内最多 5 个序列；超出改用表格。
- 图例放在图外或图上方，不遮挡数据区；图例文字用正文字体，不用等宽。
- 悬停提示需包含：系列名、X 值、Y 值、单位。提示延迟：hover 800 至 1000ms，focus 0。
- 图表必须有可访问的文本替代：容器加 `role="img"` 与 `aria-label` 描述结论；关键数据另有一张等价表格。

### 1.6 诚实性

- 只画真实数据；缺失处留占位，不用编造序列。
- 柱状图基线为 0；确需放大区间时显式标注「坐标轴自 X 起」。
- 样例数据只在产品内置示例中出现，须可识别为样例（合计成立、日期连续），并在页面标注 `data: sample`。
- 指标口径必须写明：年化方式、手续费假设、样本区间（样本内 / 样本外）。

## 2. 控件

### 2.1 输入框

| 状态 | 规范 |
| --- | --- |
| 默认 | 高 36px（应用界面）或 44px（落地页）；圆角 `--radius-sm`；边框 `--border-hairline`；内边距 12px |
| 聚焦 | 边框不变粗，使用 `outline: 2px solid var(--color-accent)` + `outline-offset: 2px`，瞬时出现 |
| 错误 | 边框改 `--color-danger`，错误文案紧贴字段下方，不置顶汇总 |
| 禁用 | 同时使用 opacity 降低 + `cursor: not-allowed` + 原生 `disabled` 属性 |
| 只读 | 与默认同高，边框改为 `--border-strong` |

- 必须有可见 `<label>`，不得只用 placeholder 当标签。
- placeholder 用 `--color-muted`，对比度不低于 4.5:1。
- 边框宽度在任何状态下恒定，避免布局跳动。
- 与相邻按钮等高。

### 2.2 按钮

| 层级 | 用途 | 样式 |
| --- | --- | --- |
| 主行动 | 页面唯一首要动作（运行策略、导出报告） | 实心 `--color-accent` + `--color-ink` 配对墨色 |
| 次行动 | 备选路径（重置、切换视图） | 实心 `--color-surface` + 1px 边框 |
| 文字按钮 | 低权重操作（展开详情） | 无底无框，`--color-accent` 文字 |
| 危险操作 | 删除、阻断策略 | 实心 `--color-danger` + 白色文字 |

- 圆角 `--radius-sm`，高度与相邻输入框一致。
- 一页只有一个实心主按钮，且不出现两个并排的实心按钮。
- 全部按钮文字用正文字体，不全大写、不加字距。
- 标签用动词短语（「运行回测」而非「提交」）。
- 禁用态用 opacity + 原生 `disabled`。
- 加载态替换为进度指示，保持按钮宽高不变。

### 2.3 标签与徽章

- 风险等级徽章：低 / 中 / 高 / 致命，色值映射见 `TOKENS.md` 1.3。
- 徽章底色用对应浅底（`--color-success-soft` 等），文字用同色系深色，保证 4.5:1 对比度。
- 徽章圆角 `--radius-pill`，内边距 4px 8px，字号 `--text-micro`（12px）。
- 徽章不使用等宽字体，不全大写。
- 徽章不承载装饰信息；状态类徽章旁不得加装饰性圆点。

### 2.4 决策结果展示

多空辩论与审计结论的呈现约定：

| 决策 | 徽章色 | 说明 |
| --- | --- | --- |
| `adopt` | 成功色 | 采纳，可进入下一环节 |
| `revise` | 警告色 | 需修订，列出具体修订项 |
| `reject` | 危险色 | 拒绝，说明否决理由 |
| `blocked` | 致命色 | 阻断，风险等级为 `critical` 时恒为此值 |

- 风险等级与决策是两个独立维度，分别用独立徽章呈现，不合并成一个标签。
- 审计问题按类别分色：`logic_flaw`（逻辑漏洞）与 `data_integrity`（数据完整性）用危险色，`overfitting`（过拟合）与 `lookahead`（未来函数）用警告色，`survivorship`（幸存者偏差）与 `liquidity_trap`（流动性陷阱）用信息色，`other` 用次要灰。类别文案与 `core/schemas.py` 的审计类别定义一致。
- 表格中的风险徽章必须带文字，不靠颜色单独表意。

### 2.5 表格

- 表头：13px 正文字体，句首大写，零字距，禁止全大写与等宽字体。
- 表头与数据行分隔用 `--border-hairline`；斑马纹可选，且用 `--color-ink-100` 低对比填充，不加边框色。
- 数值列右对齐并使用 `tabular-nums`。
- 行高不低于 40px；可点击行整行响应，hover 用 `--color-accent-soft` 高亮，不用阴影。
- 空态：说明为何为空 + 下一步可做什么，不只写「暂无数据」。

## 3. 响应式

### 3.1 断点

移动优先，断点取：

| 断点 | 宽度 | 布局变化 |
| --- | --- | --- |
| 移动 | < 640px | 单列；图表横向滚动容器内固定最小宽度 480px；表格允许横向滚动 |
| 平板 | 640px 至 1023px | 双列卡片；侧栏折叠为抽屉 |
| 桌面 | 1024px 至 1439px | 三列网格；侧栏固定 |
| 宽屏 | ≥ 1440px | 内容容器最大宽度 1360px 居中 |

- 容器最大宽度 1360px 至 1520px，超宽屏不无限拉伸。
- 网格使用 `minmax(0, 1fr)`，不用裸 `1fr`；列数不随视口宽度无上限增长。
- 页面不得出现横向滚动条；图表与宽表格在自身容器内滚动。

### 3.2 窄屏降级

| 元素 | 降级策略 |
| --- | --- |
| 多列卡片 | 折为单列，保持内容顺序不变 |
| 图表 | 简化标注密度，减少网格线；数值移入 tooltip 与下方表格 |
| 宽表格 | 容器内横向滚动，首列固定；关键列优先保留 |
| 侧栏 | 折叠为顶部抽屉，带可见关闭控件 |
| 数值卡片组 | 从网格折为纵向列表，数值与标签同行 |
| 过滤器 | 收进「筛选」按钮触发的面板，顶部显示已启用条件摘要 |

### 3.3 触控

- 触控目标最小 44×44px（WCAG 2.5.8 底线 24×24px，但金融数据产品按 44px 执行）。
- 控件间距不小于 8px。
- 不能只靠 hover 传达信息；hover 效果必须有对应的键盘 focus 与触控态。
- 自定义滑块、区间选择器需支持触控手势，不吞掉页面滚动。

## 4. 可访问性

### 4.1 对比度

| 内容 | 最低对比度 |
| --- | --- |
| 正文 | 4.5:1 |
| 大字号（≥18.66px 粗体或 ≥24px）、图标、焦点环、字段边框 | 3:1 |
| 状态信息（不得仅靠颜色传达） | 文字标签 + 形状差异 |

- 彩色表面上不使用灰色文字，次要文字取同色相。
- 强调色在纸面上承载白字时需验证对比度，不满足则改用深色墨色。

### 4.2 键盘与焦点

- 所有交互元素可键盘操作，Tab 顺序符合视觉顺序。
- 焦点环瞬时出现、对比度不低于 3:1，不得被移除且无替代。
- 焦点环不得被吸顶导航或浮层遮挡。
- 弹层打开时焦点移入，关闭时回到触发元素。
- 快捷键在界面中可见。

### 4.3 语义结构

- 标题层级不跳级（H1 → H2 → H3）。
- 每页一个 H1。
- 使用 `<button>` / `<a>` / `<input>` 等语义标签，不用 `<div onclick>`。
- 图标按钮必须有 `aria-label`。
- 图表容器加 `role="img"` 与描述性 `aria-label`，并在邻近提供等价数据表。
- 状态变化用 `role="status"` 或 `aria-live` 播报。
- 装饰性 SVG 加 `aria-hidden="true"`。

### 4.4 动效与减少动效

- 全站动效遵循 `TOKENS.md` 第 5 节的时长与缓动。
- `prefers-reduced-motion: reduce` 下减少空间位移，保留承载语义的状态与颜色变化，不整体禁用。
- 不使用闪烁超过每秒 3 次的内容。

### 4.5 文本与缩放

- 保留浏览器缩放与用户字体设置，不设置 `user-scalable=no`。
- 布局在文本放大到 200% 时不破版。
- 数字使用等宽数字特性，保证列对齐。

### 4.6 语言与元信息

- 页面声明 `lang`（如 `zh-CN`）。
- 每页有 `<title>` 与 meta description。
- 表单错误文案说明问题与恢复方式，不只说「无效」。
- 英文缩写与中文混排时保持空格一致。

## 5. 面板与页面骨架

前端形态为 `web/app/`（Vite + React 19 + TypeScript + Tailwind CSS v4），首屏动效场景以分层 SVG / canvas 实现，未引入 Three.js。以下骨架约定对组件形态与页面形态均适用。

### 5.1 研究工作台布局

```
┌─ 导航（吸顶，--z-sticky-nav）
├─ 参数栏：标的 / 策略假设 / 阈值（可折叠）
├─ 主区：图表 + 结论摘要
├─ 侧栏：风险等级、审计问题、辩论留痕
└─ 报告导出区
```

- 侧栏承载「结论与风险」，主区承载「数据与图表」，不混排。
- 数值结论用数值卡片，附文字限定语（如「样本外最大回撤 -12.4%，区间 2024-01 至 2024-12」）。
- 报告输出区提供 Markdown / HTML 双下载，与 CLI 行为一致。

### 5.2 状态完整性

每个数据区域必须覆盖五种状态：

| 状态 | 要求 |
| --- | --- |
| 加载 | 骨架或进度指示，保留最终布局尺寸，避免内容跳动 |
| 有数据 | 正常渲染 |
| 空 | 说明原因 + 可执行的下一步 |
| 错误 | 说明问题与恢复方式，提供重试入口 |
| 部分可用 | 缺失部分显式标注，不用零值填充 |

### 5.3 事实呈现

- 每个数值旁标明口径（时间区间、样本内外、费用假设）。
- 风险等级、决策、审计类别使用 `core/schemas.py` 的常量文案，不自行改写。
- 报告与页面结论一致；两者都不得出现编造数值。
